# תוכנית Milestone 2: בדיחה מ-GPT-5

## מטרה
הבדיחה מגיעה מ-GPT-5 דרך הפונקציה, והמפתח נשאר בשרת.

## מצב התחלתי (נבדק)
- `api/joke.js` מחזירה כרגע בדיחה זמנית ("המפתח: נמצא/חסר").
- ב-`index.html` כבר יש ארבעת המצבים (idle, think, joke, error), ארבעת הציורים, "עוד בדיחה!" ו"לנסות שוב". חסר: הצגת הודעת השגיאה שהשרת מחזיר (כרגע ההודעה קבועה בצד הדף).
- המפתח `OPENAI_API_KEY` כבר שמור ב-Vercel מ-Milestone 1.

## ממצאי התיעוד העדכני
- Vercel: `export default { fetch(request) }` נתמך בתיקיית `/api`. עם `"type": "module"` ב-package.json. מה שיש היום תקין, בלי שינוי.
- OpenAI Responses API: `POST /v1/responses` עם `model`, `instructions`, `input`, `reasoning.effort`, `max_output_tokens`. התשובה כוללת `output_text` (לא תמיד בבקשת REST גולמית) ו-`output` עם פריטי `message` וחלקי `output_text`. לכן יש גם חילוץ גיבוי.
- חשוב ב-GPT-5: טוקני החשיבה נספרים בתוך `max_output_tokens`. אם המגבלה נמוכה מדי, התשובה נחתכת בלי טקסט (`status: incomplete`). לכן `max_output_tokens: 1500` עם `effort: "low"`.

## לפני הקוד, ביד
1. ב-OpenAI, Billing: קרדיט מראש.
2. Auto recharge כבוי.
3. מגבלת הוצאה חודשית (Usage limits).

## קבצים לשינוי
| קובץ | שינוי |
|---|---|
| `api/joke.js` | קריאה ל-`https://api.openai.com/v1/responses` עם `fetch`. מפתח מ-`process.env.OPENAI_API_KEY`, מודל מ-`process.env.OPENAI_MODEL` או `gpt-5`. פרומפט מרכזי ב-`instructions`, ה-`input`: "נושא הבדיחה: [הנושא]" או "אין נושא. ספר בדיחה כללית על החיים.". נושא נחתך ל-100 תווים, נושא ריק או גוף שבור = בדיחה כללית. חילוץ טקסט: `output_text`, אחרת פריטי `message`. מוחזר רק `{ joke }`. שגיאות: `{ error }` בעברית (סטטוס 500/502), פרטים ב-`console.error`. מפתח חסר = 500. נשאר `console.log` אחד לכל בקשה |
| `index.html` | מציג את `data.error` מהשרת במצב שגיאה, ואם אין, הודעה כללית |

## מיפוי שגיאות OpenAI להודעות בעברית
| מצב | הודעה |
|---|---|
| 401 | יש בעיה במפתח של השרת. נסו שוב מאוחר יותר |
| 404 (מודל לא קיים) | המודל לא נמצא. נסו שוב מאוחר יותר |
| 429 (נגמר הקרדיט / מגבלת הוצאה) | השירות הגיע למגבלת השימוש. נסו שוב מאוחר יותר |
| 429 (עומס) | יותר מדי בקשות כרגע. נסו שוב בעוד רגע |
| אחר / אין טקסט | לא הצלחתי לכתוב בדיחה. נסו שוב |
